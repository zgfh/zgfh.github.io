# cilium/cilium v1.20.5 Release Notes

Published at: 2026-11-17T09:53:42Z

Summary of Changes
------------------

**Minor Changes:**
* loadbalancer: Add metrics that provide visibility into the capacity and utilisation of ID allocators within the loadbalancer control plane. (Backport PR cilium/cilium#49921, Upstream PR cilium/cilium#47746, @ajmmm)

**Bugfixes:**
* clustermesh: fix ownerReferences check in MCS-API EndpointSlice mirror (cilium/cilium#50009, @brb)
* datapath/iptables: scope iptables rules for tunnel traffic (NOTRACK) to local node addresses by matching addrtype (Backport PR cilium/cilium#50040, Upstream PR cilium/cilium#49266, @bersoare)
* datapath/loader: `getrusage` returns KiB not bytes (Backport PR cilium/cilium#49921, Upstream PR cilium/cilium#49769, @andreaterzolo)
* endpoint: use final regeneration error to resolve rollback state (Backport PR cilium/cilium#49675, Upstream PR cilium/cilium#49471, @jrajahalme)
* Extend L7 redirect ID defintion with L7 parser type, so that http and tls rules on same endpoint/port use separate proxy listeners. (Backport PR cilium/cilium#49625, Upstream PR cilium/cilium#49549, @nezdolik)
* Fix a leak of load balancer BPF map entries for NodePort services that have different external and internal traffic policies. (Backport PR cilium/cilium#49802, Upstream PR cilium/cilium#49373, @vt0r)
* Fix agent bootstrap to order endpoint regeneration after DNS proxy initialization to prevent proxy port race. (Backport PR cilium/cilium#49802, Upstream PR cilium/cilium#49540, @jrajahalme)
* Fix connections to a pod timing out when the client reuses the source port of a closed NodePort or HostPort connection to that pod. (Backport PR cilium/cilium#49625, Upstream PR cilium/cilium#47641, @aanm)
* Fix egress policy rules that combine `toServices` with `toPorts` allowing traffic to any destination on those ports when the referenced Service doesn't exist or is selector-less with no backends. (Backport PR cilium/cilium#49638, Upstream PR cilium/cilium#49430, @christarazi)
* Fix HTTP URL query not being redacted in Hubble flows when the Envoy access log URL fails to parse. (Backport PR cilium/cilium#49802, Upstream PR cilium/cilium#49427, @sage-mode-hunter)
* Fix Hubble dynamic metrics retaining deleted-pod series by applying endpoint-deletion cleanup to the active dynamic metric handlers. (Backport PR cilium/cilium#49802, Upstream PR cilium/cilium#49712, @alexcastilio)
* Fix incorrect checksums in ICMP error replies generated by Cilium. (Backport PR cilium/cilium#50040, Upstream PR cilium/cilium#49459, @yckao)
* fix incorrect CiliumEndpoint deletion during endpoint replacement (Backport PR cilium/cilium#49854, Upstream PR cilium/cilium#49573, @novikovfred)
* Fix multi-pool IPAM spreading pod IPs across multiple CIDRs instead of filling the oldest CIDRs first. This kept unused IPs from being released, so nodes held more CIDRs than they needed. (Backport PR cilium/cilium#49625, Upstream PR cilium/cilium#49418, @41ks)
* Fix nodes sending out ARP probes for their own IPs when L2 neighbor discovery is enabled. (Backport PR cilium/cilium#49802, Upstream PR cilium/cilium#49404, @rtapadar)
* Fix pods failing to reach LoadBalancer VIPs and NodePorts of eTP=Local services via kube-proxy with BPF masquerade and KPR disabled. (Backport PR cilium/cilium#49921, Upstream PR cilium/cilium#49066, @maxskokov)
* Fix restored endpoints getting only policy rules that select all endpoints. (Backport PR cilium/cilium#49802, Upstream PR cilium/cilium#49091, @jaredledvina)
* Fix strict egress encryption allowing unencrypted traffic when --encryption-strict-egress-cidr contains host bits. (Backport PR cilium/cilium#49558, Upstream PR cilium/cilium#49446, @fds7280)
* Fix the bandwidth manager dropping all egress traffic of a rate-limited pod for up to tens of seconds after a single packet carried a departure time beyond the drop horizon. (Backport PR cilium/cilium#49802, Upstream PR cilium/cilium#49653, @IraSkyx)
* Fix the datapath using empty cilium_devices maps, and "file exists" errors on endpoint regeneration, when `--preallocate-bpf-maps` is enabled. (Backport PR cilium/cilium#50040, Upstream PR cilium/cilium#49882, @spnngl)
* Fix the operator releasing ENI multi-pool IPs below min-allocate, causing nodes to immediately allocate the IPs again. (Backport PR cilium/cilium#49480, Upstream PR cilium/cilium#49125, @jaredledvina)
* Fix unintended socket termination when a backend is removed from one service but remains alive and in use by another. (Backport PR cilium/cilium#50040, Upstream PR cilium/cilium#49936, @ysksuzuki)
* Fixed an issue where DNS egress policy could deny requests after a destination’s security identity changed. DNS proxy rules now refresh alongside incremental policy updates. (Backport PR cilium/cilium#49802, Upstream PR cilium/cilium#49699, @tklauser)
* Fixes a bug that prevents cilium identity creation for pods with named ports when operator-managed-identity was enabled. (Backport PR cilium/cilium#49585, Upstream PR cilium/cilium#48662, @tamilmani1989)
* gateway-api: fix an issue when routes order might not be consistent between reconciliations. (Backport PR cilium/cilium#49802, Upstream PR cilium/cilium#49504, @arybolovlev)
* gateway-api: Prevent redundant Envoy updates from equal-precedence GRPCRoute reordering (Backport PR cilium/cilium#49625, Upstream PR cilium/cilium#49354, @weizhoublue)
* helm: Add node-role.kubernetes.io/etcd to default cilium-operator tolerations (Backport PR cilium/cilium#49802, Upstream PR cilium/cilium#49371, @ankitaojha123)
* hubble: Fixed false-positive increments of the `hubble_ring_buffer` lost events metric. (Backport PR cilium/cilium#49921, Upstream PR cilium/cilium#46585, @chez-shanpu)
* ipam: prevent full resyncs from overwriting cache updates (Backport PR cilium/cilium#49625, Upstream PR cilium/cilium#49008, @aanm)
* ipsec: allow plaintext overlay traffic during migration (Backport PR cilium/cilium#49625, Upstream PR cilium/cilium#49245, @sjohnsonpal)
* ipsec: Skip no-op XFRM policy updates (Backport PR cilium/cilium#50040, Upstream PR cilium/cilium#49883, @sjohnsonpal)
* l2announcer: Fix L2 announcements of new IPs stopping until the agent restarts after many selected services are removed at once (Backport PR cilium/cilium#49802, Upstream PR cilium/cilium#49645, @aanm)
* l2announcer: use unambiguous separator in Lease name to avoid collision (Backport PR cilium/cilium#49921, Upstream PR cilium/cilium#48138, @waterWang)
* loadbalancer: Fixes to cleaning up stale data after BPF reconciliation had encountered an error and the service or endpoints had changed before retry was performed (Backport PR cilium/cilium#49802, Upstream PR cilium/cilium#48919, @joamaki)
* loadbalancer: retry Service upserts blocked by frontend conflicts (Backport PR cilium/cilium#50045, Upstream PR cilium/cilium#49942, @mhofstetter)
* operator/ces: fix stale CES entry for recreated same-name pod (Backport PR cilium/cilium#49978, Upstream PR cilium/cilium#49824, @smagnani96)
* operator/ipam: recover ENI IPAM nodes that were dropped from the instance cache by a full ENI resync, instead of requiring an operator restart (Backport PR cilium/cilium#49480, Upstream PR cilium/cilium#46839, @ryanjwong)
* option: validate vtep-mask is an IPv4 address (Backport PR cilium/cilium#49802, Upstream PR cilium/cilium#49271, @wrzwrz123)
* pkg/ipam: Mitigate an issue where the agent reclaims an IP once the operator has started releasing it by lowering the possibility of this scenario. The operator now waits 30 minutes to release an IP by default up from 3. (Backport PR cilium/cilium#50047, Upstream PR cilium/cilium#49857, @41ks)
* Report correct source identity in drop notification for no-backend service traffic. (Backport PR cilium/cilium#49802, Upstream PR cilium/cilium#49544, @tklauser)
* Set the resource version when updating CiliumCIDRGroup. (Backport PR cilium/cilium#49921, Upstream PR cilium/cilium#47712, @bodgit)
* The cilium-operator now exits when its controller-runtime manager fails, instead of continuing to run with its controllers stopped. (Backport PR cilium/cilium#49802, Upstream PR cilium/cilium#48385, @ryanjwong)
* Use the real IPsec config in nodeHandler, which restores the `--use-cilium-internal-ip-for-ipsec` behavior (Backport PR cilium/cilium#49838, Upstream PR cilium/cilium#49827, @vakalapa)
* wireguard: Fixed an issue where transient errors updating WireGuard peers could cause AllowedIPs to remain permanently out-of-sync with the IPCache, resulting in long-term traffic disruption. (Backport PR cilium/cilium#49802, Upstream PR cilium/cilium#48664, @meel-ayush)
