- 厂商：Baidu
- 模型：ERNIE 5.5 Flash Preview（开放权重）
- 发布日期：2026-11-23
- 事件类型：开放权重
- 变化内容：百度在 Hugging Face 开放 ERNIE 5.5 Flash Preview 权重：该版本是 ERNIE 5.5 Flash Base（280B 总参数、每词元激活 14B 的 MoE）的首个官方后训练版，支持 100 万词元上下文，仓库以 FP8 量化权重加 flashindexer 发布，Apache 2.0 许可；预览 API 已于 11 月 11 日在百度智能云千帆开放。
